# Technology Stack

The Rarenest platform uses a modern web stack to achieve developer velocity, data integrity, and low-latency client-server interactions.

## Backend Core Stack

*   **Node.js (LTS)**: JavaScript runtime engine.
*   **Express.js**: Lightweight framework for routing HTTP requests.
*   **MS SQL Server / `mssql` client**: Relational database engine using T-SQL, configured for strong query compilation and structured transactions.
*   **Socket.IO**: Real-time bidirectional event-based communication protocol overlaying engine.io.
*   **JSON Web Tokens (JWT)**: Cryptographically signed security assertions for session states.
*   **Bcrypt.js**: Cryptographic library for password hashing.
*   **Multer**: Node middleware for parsing `multipart/form-data` uploads (e.g. government IDs, builder logs, property photos).
*   **Nodemailer**: Email transmission wrapper.
*   **Helmet & Cors**: Security middleware configuring HTTP headers and Allowed Origin security.
*   **Morgan**: HTTP logging framework.

## Frontend & Admin Core Stack

*   **React 18**: Component-based UI library.
*   **Vite**: Next-generation frontend build tool and dev server.
*   **Tailwind CSS**: Utility-first styling framework.
*   **React Router DOM**: Declarative client-side routing.
*   **Axios**: Promise-based HTTP client featuring request/response interceptor hooks.
*   **Socket.IO Client**: Browser client for real-time WebSocket connection channels.
*   **Lucide React**: Vector icon asset library.
*   **Shadcn UI (Radix UI)**: Customizable accessible primitives.
*   **React Tanstack Query**: Server side state management.
*   **Redux  toolkit** :    Client side state management
